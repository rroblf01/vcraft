# Code of conduct

vcraft follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, critique code and ideas rather than people, and
leave the conversation better than you found it.

Report unacceptable behaviour privately to the maintainers through the contact in
[SECURITY.md](SECURITY.md); reports are handled confidentially.
